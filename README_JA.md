# GitHub Pages 用・編集できるデザインサンプル

2026年11月19日時点の Isomorphic Labs トップページを見て、レイアウト・余白・配色・カード構成・基本の動きを独自に実装した静的サイトです。

**写真・立体画像・文章・ロゴ・フォント・細かなアニメーションは原サイトと同一ではありません。ピクセル単位の完全複製ではありません。** 原サイトのソースコード、人物写真、動画、ロゴ、有料フォントは含めていません。トップページ以外は同じデザインのルールで作った編集用サンプルです。

## 最初に開くもの

- `index.html`：サイト本体。展開後にダブルクリックで開けます。
- `editor.html`：日本語の編集画面。色、社名、文章、写真パス、リンク、メールなどを変更できます。
- `GUIDE.html`：公開・編集手順。ブラウザで読めます。

ZIPをアップロードするのではなく、展開したファイルと `assets` フォルダーをアップロードしてください。`index.html` がリポジトリの一番上に並ぶ構造にします。

## 無料での公開手順

1. GitHubにログインし、右上の「+」→「New repository」を選びます。
2. Repository name に `company-design-study` などを入力します。
3. Visibility を **Public** にします。GitHub FreeでPagesを使う場合は公開リポジトリが必要です。
4. 「Add README」をオンにして「Create repository」を押します。
5. 新しいリポジトリで「Add file」→「Upload files」を選びます。
6. このフォルダーの**中身**をアップロードします。`index.html`、`page.html`、`site.config.js`、CSSとJS、`assets` フォルダーなどを入れます。ZIPそのもの・外側のフォルダーを丸ごと置かないでください。
7. 「Commit changes」で保存します。
8. 「Settings」→左の「Pages」を開きます。
9. Source を **Deploy from a branch**、Branch を **main**、Folder を **/(root)** にして「Save」を押します。
10. 公開処理が終わったら「Visit site」を押します。反映に最大10分程度かかることがあります。

通常の公開URLは `https://ユーザー名.github.io/リポジトリ名/` です。独自ドメインを購入しなければ、ドメイン取得費用もかかりません。

このサイトはHTML・CSS・JavaScriptだけで動きます。Node.js、npm、ビルド、独自のGitHub Actions設定は不要です。`.nojekyll` は同梱しています。Windowsで見えない場合、ファイル名から `.html` などを削らずそのまま扱ってください。

## 編集する方法

1. `editor.html` を開きます（公開後はサイトのURLの末尾に `editor.html` を付けても開けます）。
2. 「編集する項目」で変えたい箇所を選びます。
3. 文字・色・リンクなどを変更して、右側のプレビューを確認します。
4. **設定ファイルを保存**を押して、`site.config.js` をダウンロードします。
5. 同名のファイルを手元のフォルダーとGitHubリポジトリで置き換えます。
6. GitHubで「Commit changes」を押すとPagesが更新されます。

編集画面はプレビューとファイル書き出し用です。**編集しただけでは公開サイトは更新されません。** 他の人が編集画面を開いても、あなたのGitHubに書き込むことはできません。ログインやパスワード入力はありません。ページを閉じる前に保存してください。

| 変えたい内容 | 編集画面の項目 / 設定 |
|---|---|
| 社名・ロゴ | 社名・ロゴ・検索表示 / `brand` |
| 背景色・文字色・フッター色 | 色・背景画像の色合い / `theme` |
| 写真や立体画像の色合い | `theme.imageHue`（色相。画像そのものの配色を自由に塗り分ける機能ではありません） |
| トップの見出し・背景画像 | トップの見出し・画像 / `home.hero` |
| その他の文章 | 対応する各セクション / `home`、`pages` |
| ニュースと記事本文 | ニュース・記事本文 / `news` |
| メニュー・リンク | メニュー・リンク / `navigation` |
| メールアドレス | 連絡先・フッター / `footer.email` など |
| アニメーションの有無 | 動きの設定 / `motion.enabled` |
| 非公式サンプルの説明 | デザインサンプルの表記 / `study` |

### 写真を入れ替える

1. 自社の写真を `assets` フォルダーに入れます。英数字・ハイフンのファイル名をおすすめします。例：`founder.jpg`。
2. 編集画面の画像パスを `./assets/founder.jpg` にします。
3. 人物写真の **2枚組の仮画像** をオフにします。現在の仮画像は2人分を横に並べた1枚なので、この設定で半分ずつ表示しています。
4. 新しい画像もGitHubへアップロードします。設定ファイルだけの変更では画像は追加されません。

背景動画を使う場合は、自社で使用できるMP4を `assets` に入れ、該当箇所の `video` にパスを指定します。空欄なら画像が表示されます。動画はデータ量が大きいため短く軽いファイルにしてください。

### 日本語にする

文章を日本語へ書き換え、「ページの言語」を `ja` にします。フォントは日本語対応のシステムフォントに切り替わります。日本語の分量によって改行が変わるので、PCとスマホの両方を確認してください。

### リンクを変える

同じサイト内は `./page.html?view=work` のような相対パス、外部サイトは `https://...` を使います。先頭が `/assets/...` のようなパスだとプロジェクト用Pagesで階層がずれるため、`./assets/...` にしてください。

メールアドレスは未設定です。設定すると `mailto:` のリンクになり、閲覧者のメールアプリが開きます。フォームから送信する仕組みは付けていません。

## サンプルから自社の正式サイトにする場合

現在は非公式・学習用の表示と `noindex` を付けています。社名を差し替えるだけで原サイトの写真・ロゴ・文章・動画等を自由に再利用できるようになるわけではありません。正式公開には自社で使用できる素材と文面を使ってください。

GitHub Pagesは、個人・組織・プロジェクトを紹介する静的ページを公開できます。ただしGitHubは、オンライン事業の運営や商取引・SaaSを主目的とするサイトなどの無料ホスティング利用を制限しています。**自社サイトに変更した後もあらゆる商用用途に無料で使える、という意味ではありません。** 正式運用の目的に適合するか、下記の公式説明を確認してください。

デザイン学習用の再現サイトについては、独自コード、データを収集しないこと、原サイトとの無関係・学習目的を目立つ場所に表示することがGitHubの説明にあります。このサンプルはその形で作成しています。

自社サイト化を終えて検索に載せる場合は、`study.enabled` を `false` にすると動的なrobots指定は `index,follow` になります。加えて **index.html と page.html の `<meta name="robots">` を静的にも `index,follow` に変更**してください。SEOを重視する正式運用では、ページごとに本文・タイトル・OGPを含む静的HTMLを出力する構成も検討してください。この版は後から編集しやすいデザイン確認用です。

## 機能と対応範囲

- PC・スマホ対応。
- トップページの主要なセクションを再現。
- ドロップダウン・スマホメニュー、ミッションの開閉。
- 抽象的な立体画像のゆっくりした動き、回転する点群、スクロール時の表示。
- 動きを止めるボタン、OSの「視差効果を減らす」への対応。
- 下層のサンプルページ、ニュース一覧と記事詳細。
- 色・全テキスト・リンクなどの編集、プレビュー、設定の保存・再読込。
- すべての画像とフォントを同梱。外部CDNが停止しても基本表示は維持。

元サイト固有の動画や高度な3D表現、全下層ページの完全複製、CMS、アクセス解析、問い合わせフォーム、メール送信、予約、決済、ログインは含みません。

## うまく表示されない場合

- **404**：Settings → Pages のbranch/folder、アップロードした `index.html` の位置を確認します。Actionsの最新処理が完了するまで待ちます。
- **画像が出ない**：画像のアップロード忘れ、ファイル名の大文字小文字、`./assets/...` のパスを確認します。
- **変更が反映されない**：`site.config.js` をCommitしたか確認し、公開処理完了後に強制再読み込みします。
- **ZIPを開いても動かない**：まずZIP全体を展開してから `index.html` を開きます。
- **編集画面が動かない**：新しいChrome/Edgeで開いてください。手元で制限される場合は、公開済みサイトの `editor.html` で編集できます。

## ファイルと素材

`index.html` / `page.html`：HTML入口。`site.config.js`：全設定。`styles.css`：デザイン。`app.js`：表示と操作。`motion.js`：点群アニメーション。`editor.*`：編集画面。`assets`：画像・フォント。

画像2点はこのサンプル用に生成したオリジナルの仮素材です。人物は架空です。フォントはInter（SIL Open Font License 1.1）。ライセンスは `assets/Inter-OFL.txt` に同梱しています。
